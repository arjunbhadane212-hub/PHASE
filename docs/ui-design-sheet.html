Component rules
  • Back button — 40px pill, top-left of every sub-screen and modal.
  • Colour tile — 24px radius, min 128px, icon top, name bottom.
  • Section hero — the tile grows into it (28px radius, 32px title).
  • Tabs — card pills; the ink pill slides to the active one.
  • Habit row — slot colour block → lime when done, check pops in.
  • Rings / bars — fill from zero, round caps, on the track colour.
  • Motion rings — always previewed on a dark stage.
  • Nav — floating pill, white (light) / charcoal (dark), ink disc slides.
Icons

Phosphor, bold by default, fill when active. 18–22px in rows, 30px in tiles, 42–44px in heroes. Import through components/icons, one icon per deep import. No emoji in the real UI (the emoji above are only stand-ins on this sheet).

Motion

ease-out-quint cubic-bezier(.22,1,.36,1) · 0.3 / 0.5 / 0.65s · spring 260/30 for sliding pills. Nothing teleports, nothing glows.

Do / don't

Do
  • Solid pastel blocks with their own ink
  • Big, bold type and numbers
  • Pills and 24–28px rounded blocks
  • Separate by tone, not shadow
  • Same colour = same meaning
  • Back button on every sub-screen
Don't
  • Purple — anywhere
  • Pastel text on paper
  • Thin fonts or uppercase mono labels
  • Glow, shimmer, neon, glass, blur
  • Diagonal gradients, gradient text
  • Dead ends that need the nav to escape
